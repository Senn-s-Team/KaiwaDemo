# 用户测试记录模板

> **文档性质**：人工执行记录模板；用于记录一次当前产品验收、模型评价质量复核或研究流程，不是产品规格。
> **权威范围**：本文件只规定人工执行时要记录的事实、证据和决策门槛；当前产品行为以 [产品契约](./product-contract.md) 为准，工程实现边界以 [系统边界](./system-boundaries.md) 为准。
> **非权威范围**：本文不证明统计显著性、语言能力、发音质量或长期迁移，也不把自动测试通过写成模型评价正确或学习效果成立。
>
> [PROTOCOL]: 变更时更新此头部，然后检查 AGENTS.md

## 使用说明

- 每次测试先填写“测试者与环境”，再按 A、B、C 中适用的部分记录；未执行的部分标为“未执行”，不得填写为通过。
- 只记录可观察事实。评价结论必须附人工证据；没有观察机会记为“未观察”或“证据不足”，不得推断为失败或成功。
- 使用匿名编号、脱敏文本或录音/转写编号。不要记录姓名、联系方式、账号、真实地址、支付信息或其他不必要的敏感资料。
- 录音、转写、截图、导出 JSON 和错误信息均应使用同一匿名编号，并注明日期、场景标识、评价版本（如有）和运行模式。
