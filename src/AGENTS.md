成员清单
App.tsx: 前端产品编排根组件，连接动态场景准备、固定五回合会话、四级听力与表达支架、录音与转写、单场恢复、复盘和重做流程
App.css: 应用级组件布局、会话状态、录音反馈、听力与表达支架、失败重试和完成页视觉规则
types.ts: 前端动态场景、会话阶段、消息、按消息听力支架缓存、回合指标、恢复和报告的领域类型总入口
main.tsx: React 浏览器启动入口与根节点挂载
index.css: 全局基础样式、字体和页面默认渲染规则
lib/: 音频、STT/TTS、API、会话状态机、指标与辅助纯规则，包括听力支架 endpoint 客户端
components/: 可复用界面组件边界，当前没有直属实现
data/: 本地训练内容与词汇数据源
scenarios/: 前端场景适配边界，当前没有直属实现
assets/: 构建期打包的图片与静态视觉资源
