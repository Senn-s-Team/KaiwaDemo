成员清单
App.tsx: 前端产品编排根组件，组合首页/完成页/活动会话视图及专职恢复、控制器与仅内存遥测生命周期
App.css: 应用级组件布局、中文场景实时语音、润色与等待状态、会话音频、渐进帮助、失败重试、完成页及静态隐私选择视觉规则
types.ts: 前端动态场景、会话阶段、消息、按消息听力支架缓存、回合指标、恢复、版本化证据评价、长期复练凭据和报告的领域类型总入口；不含遥测凭据
main.tsx: React 浏览器启动入口与根节点挂载
index.css: 全局基础样式、字体和页面默认渲染规则
lib/: 音频、STT/TTS、API、会话状态机、场景与复盘恢复、本机练习历史、表现比较、阶段纯规则和同意式匿名验证生命周期边界
components/: 可复用界面组件边界，含 ActiveSession 活动会话、Home 首页准备与 SessionComplete 完成复盘视图
data/: 本地训练内容与词汇数据源
scenarios/: 前端场景适配边界，当前没有直属实现
assets/: 构建期打包的图片与静态视觉资源
