成员清单
App.tsx: 前端产品编排根组件，连接中文场景语音输入、固定五回合会话、内部渐进帮助、录音与转写、可暂停相手语音、单场恢复、证据复盘和重做流程
App.css: 应用级组件布局、中文场景语音输入状态、会话音频、渐进帮助、失败重试和完成页视觉规则
types.ts: 前端动态场景、会话阶段、消息、按消息听力支架缓存、回合指标、恢复、版本化证据评价、长期复练凭据和报告的领域类型总入口
main.tsx: React 浏览器启动入口与根节点挂载
index.css: 全局基础样式、字体和页面默认渲染规则
lib/: 音频、STT/TTS、API、会话状态机、指标与辅助纯规则，包括听力支架 endpoint 客户端、本机练习历史与表现比较
components/: 可复用界面组件边界，当前没有直属实现
data/: 本地训练内容与词汇数据源
scenarios/: 前端场景适配边界，当前没有直属实现
assets/: 构建期打包的图片与静态视觉资源
